## Project Overview

This project focuses on cleaning the Beijing Multi-Site Air Quality Dataset using R Programming. The objective is to identify and handle missing values, implement reusable functions, use loops for data processing, perform error handling with `tryCatch()`, and export a cleaned dataset suitable for further analysis.

---

## Dataset

- **Dataset:** Beijing Multi-Site Air Quality Dataset
- **Station Used:** PRSA_Data_Aotizhongxin_20130301-20170228.csv

---

## Tasks Performed

- Imported and inspected the dataset
- Identified NA, NULL, and NaN values
- Created a missing value summary function
- Calculated pollution ratio (PM2.5 / PM10)
- Replaced missing numerical values using the median
- Replaced missing categorical values using the mode
- Implemented error handling using `tryCatch()`
- Compared missing values before and after cleaning
- Generated a bar chart for missing values
- Exported the cleaned dataset
